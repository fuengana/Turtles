# Recursive Spiral 

This project uses Python's built-in **turtle graphics** module to draw a colorful spiral pattern.  
It's a simple but cool way to explore loops, geometry, and visual creativity with with Python.

<br> Black: Cursor <br> 
<br> Red: Tree  <br> 
<br> Blue: Leaf <br> 
<br> Switched Around For Tree and Leaf As Numpy <br> 
<br> Green: Marijuana <br> 
<br> Design Implication is Lighting Principle, Sun Babylonian Fall <br> 

## Preview
Running the script will generate a spiral made up of repeating shapes and colors from the classic RGB values similar to digital art created by a spirograph.
